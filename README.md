# Editör+ — masaüstü sürümleri

Bu repo yalnız **Editör+** masaüstü uygulamasının kurulum dosyalarını ve otomatik güncelleme manifestini (`latest.json`) dağıtır. Kaynak kod burada değildir.

## İndir

İndirme ve kurulum adımları: **https://editor.sedat.me/indir**

| Sistem | Dosya |
|---|---|
| Windows 10 / 11 (64 bit) | [EditorPlus-windows-x64-setup.exe](https://github.com/soylemezs/editorplus-releases/releases/latest/download/EditorPlus-windows-x64-setup.exe) |
| macOS 11+ (Intel ve Apple Silicon) | [EditorPlus-macos-universal.dmg](https://github.com/soylemezs/editorplus-releases/releases/latest/download/EditorPlus-macos-universal.dmg) |

Uygulama henüz bir işletim sistemi yayıncı sertifikasıyla imzalanmadı; ilk açılışta Windows SmartScreen veya macOS Gatekeeper uyarı verebilir. Adımlar indirme sayfasında. Güncellemeler uygulama içinden gelir ve imzayla doğrulanır.

Görseller bilgisayarınızda işlenir; hiçbir görsel sunucuya gönderilmez.
